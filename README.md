# 故事森林网站

一个以故事浏览和阅读为主题的静态网站项目。网站提供首页展示、故事分类、个性化推荐、分页浏览和故事详情阅读等页面，适合作为 HTML/CSS/JavaScript 前端练习项目。

## 项目预览

项目名称：故事森林

项目类型：静态网页 / 故事阅读网站

主要语言：HTML、CSS、JavaScript

当前版本：本地静态演示版

## 功能介绍

- 首页展示网站主题、热门故事和故事卡片
- 分类页按故事类型和篇幅筛选内容
- 推荐页展示热门故事和推荐内容
- 推荐分页页支持继续浏览故事列表
- 11 个故事详情页，可进入独立页面阅读故事
- 故事搜索交互
- 登录和注册弹窗交互
- 用户信息展示与注销交互
- 收藏、评分、浏览量等故事信息展示
- 响应式布局，适配桌面端和移动端
- 音乐播放器及背景音乐资源
- 图片资源和故事页面均使用本地文件保存

> 说明：当前项目没有连接后端数据库，登录、注册、搜索和收藏等功能主要用于前端界面与交互演示，数据不会同步到服务器。

## 运行项目

### 方法一：直接打开

双击打开 `1网站首页.html`，即可查看网站首页。

### 方法二：使用 VS Code Live Server

1. 使用 VS Code 打开 `工程` 文件夹。
2. 安装并启用 **Live Server** 插件。
3. 右键点击 `1网站首页.html`。
4. 选择 **Open with Live Server**。

推荐使用 Live Server 运行，这样页面跳转、本地资源加载和浏览器调试会更加稳定。

## 技术特点

- 使用语义化 HTML 搭建页面结构
- 使用 CSS 完成布局、颜色、动画和响应式效果
- 使用 JavaScript 实现搜索、筛选、弹窗、登录注册和音乐播放等交互
- 使用 Tailwind CSS 工具类辅助页面布局和样式开发
- 使用本地图片和音频资源，减少对后端服务的依赖

## Git 初始化与提交

在 `工程` 文件夹中打开终端，执行：

```bash
git init
git add .
git commit -m "初始化故事森林网站"
```

如果需要关联 GitHub 远程仓库：

```bash
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main
```

请将命令中的远程仓库地址替换为自己的 GitHub 仓库地址。
